# แผนโปรเจกต์: ระบบติดตามงานทีม

> เอกสารนี้ผู้สอนเตรียมไว้ให้ ผู้เรียนอ่านให้เข้าใจแล้วเริ่มที่ขั้น Design ได้เลย ถ้าจะเปลี่ยนขอบเขต ให้แก้ไฟล์นี้ก่อนสั่ง Codex

## ปัญหาและเป้าหมาย

ตอนนี้ทีมมอบหมายงานกันผ่านแชทกลุ่มและตาราง Excel ข้อความจมหายง่าย ไม่รู้ว่างานไหนใครรับไป ทำถึงไหนแล้ว หรือเลยกำหนดส่งหรือยัง หัวหน้าต้องไล่ถามทีละคน

**เป้าหมาย:** เว็บที่หัวหน้าทีมสร้างงานและมอบหมายให้สมาชิกได้ ผู้รับงานอัปเดตสถานะเอง ทุกคนในทีมเห็นความคืบหน้าในที่เดียว และคนนอกทีมมองไม่เห็นงานของทีม

## ผู้ใช้

| กลุ่ม | ต้องการอะไร | ใช้ผ่าน |
|---|---|---|
| หัวหน้าทีม (คนที่สร้างทีม) | สร้างทีม แจกรหัสเชิญ สร้างงาน มอบหมาย และติดตามความคืบหน้า | เว็บไซต์ |
| สมาชิกทีม | เข้าร่วมทีมด้วยรหัสเชิญ ดูงานของทีม และอัปเดตสถานะงานที่ได้รับ | เว็บไซต์ |

## ขอบเขต MVP

### ทำในรอบนี้

1. สมัครสมาชิกพร้อมชื่อที่แสดง ล็อกอิน และออกจากระบบ
2. สร้างทีม หรือเข้าร่วมทีมด้วยรหัสเชิญ (1 คนอยู่ได้ 1 ทีม)
3. หัวหน้าสร้างงานและมอบหมายให้สมาชิก ทุกคนในทีมเห็นงานแบ่งตามสถานะ
4. ผู้รับงานเปลี่ยนสถานะงาน (ยังไม่เริ่ม → กำลังทำ → เสร็จแล้ว) และงานที่เลยกำหนดมีป้ายเตือน
5. หน้า "งานของฉัน" (งานเสริม)
6. ส่งอีเมลแจ้งผู้รับงานเมื่อได้รับมอบหมาย (งานเสริม)

### ไม่ทำในรอบนี้

- แก้ไขหรือลบงานผ่านหน้าเว็บ (ถ้าจำเป็น หัวหน้าลบผ่าน Supabase Table Editor)
- อยู่หลายทีมพร้อมกัน ออกจากทีม เปลี่ยนหัวหน้า หรือเตะสมาชิกออก
- ความคิดเห็นในงาน แนบไฟล์ งานย่อย
- แจ้งเตือนก่อนถึงกำหนดส่ง และอีเมลแบบอื่นนอกจากแจ้งเมื่อได้รับมอบหมาย
- ล็อกอินด้วย Google หรือบัญชีอื่น

## Stack

Next.js (App Router) + Supabase (Postgres, Auth, RLS) + Vercel โดยเขียนโค้ดด้วย Codex ใน VS Code · งานเสริมส่งอีเมลใช้ Gmail SMTP

## ความเสี่ยงและข้อจำกัด

| ความเสี่ยง | แนวทาง |
|---|---|
| งานของทีมรั่วไปถึงคนนอกทีม | เปิด RLS ทุกตาราง ให้เห็นเฉพาะข้อมูลของทีมตัวเอง |
| สมาชิกแอบแก้งานที่ไม่ใช่ของตัวเอง หรือแก้ชื่องาน/ผู้รับงาน | บังคับในฐานข้อมูล: ผู้รับงานแก้ได้เฉพาะสถานะ หัวหน้าแก้ได้ทั้งหมด ไม่ใช่แค่ซ่อนปุ่มบนหน้าจอ |
| มอบงานให้คนนอกทีม หรือ 1 คนเข้าหลายทีม | ตรวจในฐานข้อมูลด้วย policy และ unique constraint |
| ผู้ใช้ยังไม่อยู่ในทีม จึงอ่านตาราง teams เพื่อหารหัสเชิญไม่ได้ | สร้างทีมและเข้าร่วมทีมผ่าน function ในฐานข้อมูล ซึ่งตรวจรหัสให้โดยไม่เปิดตาราง teams ให้คนนอกอ่าน |
| ชื่อและอีเมลของสมาชิกเห็นได้ในทีม | ให้เห็นเฉพาะเพื่อนร่วมทีม คนนอกทีมไม่เห็น |
| key หลุดขึ้น GitHub | เก็บใน `.env.local` ซึ่งอยู่ใน `.gitignore` และใช้ publishable key ฝั่ง browser เท่านั้น |
| App Password ของ Gmail หลุด (เข้าบัญชีได้ทั้งบัญชี) | ใช้บัญชี Gmail ที่สมัครไว้ทดลองโดยเฉพาะ เก็บใน `.env.local` และ Environment Variables ของ Vercel ใช้ในโค้ดฝั่ง server เท่านั้น ห้ามขึ้นต้นด้วย `NEXT_PUBLIC_` และลบ App Password เมื่อเลิกใช้ |
| Supabase แบบฟรีส่งอีเมลยืนยันตัวตนได้จำกัดมาก | สำหรับ workshop ให้**ปิด Confirm email** ใน Supabase → Authentication → Sign In / Providers → Email เพื่อให้สมัครแล้วใช้ได้ทันที (เมื่อใช้งานจริงต้องเปิดกลับ และตั้งค่า SMTP ของตัวเอง) |
| มีเวลาทำ 3 ชั่วโมง | ทำทีละ user story ตามลำดับ US-1 → US-6 ถ้าไม่ทันให้ deploy ส่วนที่ทำเสร็จแล้ว |

## สมมติฐานที่ปรับได้

- คนที่สร้างทีมเป็นหัวหน้าทีมคนเดียวของทีมนั้น
- สมาชิกทุกคนในทีมเห็นรหัสเชิญ และชวนเพื่อนเข้าทีมได้
- หัวหน้ามอบงานให้ตัวเองได้
- งาน 1 ชิ้นมีผู้รับงาน 1 คน
- วันกำหนดส่งเป็นวันที่ (ไม่มีเวลา) ตามเวลาประเทศไทย (Asia/Bangkok) งานเลยกำหนดเมื่อวันนี้เลยวันกำหนดส่งแล้วและยังไม่เสร็จ
