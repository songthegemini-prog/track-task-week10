# Bug Fix

หาสาเหตุให้เจอก่อนแก้ อธิบายให้ผู้ใช้เข้าใจ แล้วแก้ให้น้อยที่สุดที่ทำให้หายจริง


## คุยกับผู้ใช้ที่ไม่ใช่โปรแกรมเมอร์

- ตอบเป็นภาษาไทยที่เข้าใจง่าย อธิบายศัพท์เทคนิคสั้น ๆ ในวงเล็บทุกครั้งที่ใช้ครั้งแรก
- สรุปการเปลี่ยนแปลงเป็นภาษาคน ไม่ต้องให้ผู้ใช้อ่านโค้ดทุกบรรทัด
- จบงานด้วยหัวข้อ **"สิ่งที่คุณต้องทำเอง"** เป็นข้อที่คลิกหรือพิมพ์ตามได้ทันที (เมนูไหน ปุ่มไหน วางอะไร)

## 1. เก็บข้อมูล

ถ้าข้อมูลไม่พอ ให้ขอเฉพาะที่ขาด:

- อาการ และขั้นตอนที่ทำให้เกิด (กดอะไร ลำดับไหน)
- ผลที่คาดหวัง เทียบกับผลที่เกิดจริง
- error จาก browser console, terminal หรือ Vercel logs
- เกิดที่ไหน: localhost, Preview หรือ Production และเกิดกับทุกบัญชีหรือบางบัญชี

เตือนผู้ใช้ว่า**ห้ามวาง secret key หรือข้อมูลส่วนตัวของผู้ใช้จริง**มาในแชท

## 2. จำกัดวง

| อาการ | สงสัยก่อน |
|---|---|
| query สำเร็จแต่ได้ข้อมูลว่าง | RLS ไม่ให้อ่าน (ไม่มี policy, ผิด role, ผู้ใช้ไม่ได้ล็อกอิน หรือ client ไม่ได้ผูก session) |
| insert/update error เรื่อง row-level security | `with check` ไม่ผ่าน เช่น ไม่ได้ส่ง `user_id` ที่ตรงกับ `auth.uid()` |
| ใช้ได้บนเครื่อง พังบน Vercel | env vars ไม่ได้ตั้ง ตั้งผิด environment หรือยังไม่ redeploy |
| ล็อกอินแล้วเด้งไปผิดที่ | Site URL / Redirect URLs ใน Supabase Auth |
| build บน Vercel ไม่ผ่าน | error ของ TypeScript/lint ที่บนเครื่องข้ามไป หรือรุ่น Node ไม่ตรงกัน |

อ่านโค้ดและ log ที่เกี่ยวข้อง แล้วเขียนสมมติฐานของสาเหตุพร้อมหลักฐาน ถ้ามีหลายสมมติฐาน ให้เรียงตามความน่าจะเป็น และเสนอวิธีพิสูจน์ที่ถูกที่สุดก่อน

## 3. แก้

- อธิบายสาเหตุให้ผู้ใช้ก่อนแก้ ถ้าการแก้เปลี่ยนพฤติกรรมของระบบหรือเปลี่ยนข้อกำหนด ให้ถามก่อน
- แก้ที่ต้นเหตุทีละจุด ไม่แก้หลายอย่างพร้อมกันจนไม่รู้ว่าอะไรได้ผล
- **ห้ามแก้ด้วยการปิด RLS, เขียน policy `using (true)` บนข้อมูลส่วนบุคคล หรือย้าย secret key ไปฝั่ง browser** ถ้าดูเหมือนเป็นทางเดียว ให้หยุดแล้วอธิบายทางเลือกที่ปลอดภัย
- ถ้าต้องแก้ฐานข้อมูล ให้เขียน migration ใหม่ใน `supabase/migrations/` และให้ผู้ใช้เป็นคนรัน

## 4. กันไม่ให้กลับมา

- เพิ่ม test ที่ล้มก่อนแก้และผ่านหลังแก้ ถ้าทำได้ ถ้าทำไม่ได้ ให้เขียนขั้นตอนทดสอบด้วยมือ
- รัน lint, test และ build แล้วรายงานผลจริง
- ถ้าบั๊กนี้เกิดจากรูปแบบที่อาจเกิดซ้ำ ให้เสนอกฎ 1 บรรทัดเพิ่มใน `AGENTS.md` หรือ Skill ที่เกี่ยวข้อง
- สรุป: สาเหตุ, สิ่งที่แก้, ไฟล์ที่เปลี่ยน, วิธีทดสอบ และข้อความ commit ที่แนะนำ
